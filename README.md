## 简介
《旅行时光：饥饿》是一款中型 Minecraft Java 版整合包，整体难度较高，定位为 **偏硬核生存向**。包含 200+ 模组，围绕生存挑战、维度探索、饮食烹饪、战斗装备四条主线展开，适合想要体验硬核玩法但又了解不深的玩家，可作为向更高难度整合包过渡的入门选择。

## 核心特色

- **硬核生存机制**
  - 传说生存：拟真的受伤、温度、口渴与肢体健康系统，受伤后需合理休养。
  - 无树可撸：初期无法直接空手伐木，需通过燧石工具逐步解锁木材获取。
  - 静谧四季：季节更替影响天气与温度，不同季节有不同生存策略。
  - 僵尸意识：僵尸会感知声音与光源，大幅提高夜间生存压力。
  - 遗体：死亡后掉落遗体，需返回拾取物品，增加死亡惩罚。

- **维度探索**
  - 暮色森林：经典维度冒险，包含大量独特生物、地牢与 Boss 战。
  - 天境：高空浮岛世界，全新的生物、结构与探索体验。
  - Alex 的洞穴：地下洞穴维度，充满史前生物与奇异景观。
  - 幽邃黑暗：深层深渊维度，探索地底深处的未知恐怖。
  - 天境：遗失之物：为天境补充更多内容与玩法。

- **生物与战斗**
  - Alex 的生物：新增 90+ 种生物，涵盖陆地、海洋与天空。
  - 匠魂：深度自定义工具与武器锻造系统，可自由组合材料与属性。
  - 斯巴达的武器 & 斯巴达之盾：新增十几种武器类型与盾牌，拓宽战斗风格。
  - YDM 的武器大师：武器技能与战斗动作系统。
  - 更好的战斗：双持攻击、攻击连段等战斗手感优化。
  - 奇异饰品：探索中获得各类饰品，提供被动加成与特殊效果。

- **饮食烹饪（10+ 乐事系列）**
  - 农夫乐事：扩展耕作与烹饪系统，提供基础烹饪锅具。
  - 末地乐事 / 下界乐事 / 天境乐事 / 洞穴乐事：各维度专属食材与菜肴。
  - 海洋乐事 / 蟹农乐事 / 矿工乐事：拓展水产、蟹类与矿洞食材。
  - 烧烤乐事 / 存储乐事 / 装箱乐事：烧烤聚会玩法、食物保鲜存储与物流。

- **世界生成**
  - 动态的树：树木生长更为真实，砍伐时整棵树倾倒，附带多维度和匠魂兼容。
  - CTOV & YUNG 系列 & Moog 系列：大幅丰富主世界、下界、末地的结构生成（村庄、地牢、要塞、矿井、海底神殿等 20+ 种）。
  - 潮汐小镇 & 更好的考古学：沿海小镇与古代遗迹探索。
  - Tectonic：地形生成大修，山脉、河流更加壮丽真实。

- **便捷与辅助**
  - JEI 物品管理器 / 玉（Jade） / 苹果皮：核心信息显示。
  - 连锁采矿 / 多人开采 / 右击收获：减少重复劳作。
  - 精妙背包：多层背包系统，支持升级与自动化整理。
  - 传送石碑 / 指路石：便捷传送网络。
  - FTB 任务 & 团队：内置任务引导与团队协作。
  - 通用拼音搜索 / 自动汉化更新 / 模组汉化器：中文搜索与持续汉化。

- **沉浸体验**
  - 脚步声 / 物理声效 / 自然音效 / 网络音乐机：丰富的环境音效与自定义音乐。
  - 增强视觉效果 / 更多动画 / 物品物理掉落：视觉与物理效果增强。
  - 沉浸式飞机：可制作的飞行器，用于中后期探索。
  - 梦醒时分 & 舒适用品：睡眠加速时间，睡袋与吊床野外休息。
